# Nop Platform 2.0 代码路线图（研究态）

## 1. 入口点（Entry Points）
- `nop-quarkus-demo`：Quarkus 集成示例，`QuarkusDemoMain` 启动 Quarkus 并托管 `NopApplication`。【F:nop-demo/nop-quarkus-demo/src/main/java/io/nop/demo/quarkus/QuarkusDemoMain.java†L20-L34】
- `nop-spring`：与 Spring 框架的适配层，提供 `nop-spring-web-orm-starter` 等启动器以复用 ORM/GraphQL 能力。【F:docs/dev-guide/integration/nop-on-orange-form.md†L91-L118】
- `nop-cli`：命令行工具集合，封装 `nop-codegen` 与监听功能，支持生成任务快速执行。【F:docs/dev-guide/codegen.md†L73-L107】

## 7. 热点与风险（Hotspots）
- 模型一致性：多个引擎共享模型定义，需防止版本漂移。
